# Experiment parameter sets

Each file here is the full tuning schema, byte-for-byte
[tuning.defaults.json](../tuning.defaults.json) with one
`l5.cv_kf_v1.solid_body` block added, so a run from it and a run from the
defaults differ in that block and nothing else. A test holds that. The
sets, the replay experiment names they replace, and how to run one are in
[CONFIG.md](../CONFIG.md#experiment-parameter-sets).
