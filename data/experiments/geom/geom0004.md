# geom0004: where reviewed road users' returns are lost

**Question.** W3 found that half of kirk0's reviewed road-user returns never reach a cluster, that
pedestrians keep 17%, and that truck 2's cab is a retention loss; the range-adaptive eps found that
fragmentation at 20 to 50 m is not beam spacing. Neither evidence could say where a return was
lost. For every reviewed return, which stage drops it: the L3 background, the height band, the
DBSCAN input cap, DBSCAN noise or a cluster filter? And what lies between a fragmented object's
clusters?

**Method.** Replay kirk0 under the shipped defaults and CMR into the foreground-complete
observation container, which records every L3 foreground return and the reason L4 set any of
them aside, and join it to the reviewed masks by return identity.

**Success.** Fate shares by class, range band and named object, with the match rate stated, that
say which stage to change next for pedestrians, truck 2's cab and the 20 to 50 m fragments, and
how much of that CMR already recovers.
