# l3bg0019: where the Stage B arms lose a reviewed return

**Question.** Under CMR the returns between a truck's fragments at 20 to 35 m are 93 % returns
L3 still absorbs, and the input cap report asked whether the dwell policy or the cell tercile,
both Stage B arms or candidates, touch them. The fate measure costs about 15 s of CPU an arm.
Which stage loses each reviewed return under each arm, and do the mid-range gaps move?

**Reading, written before the replays (2026-10-18).** A measurement, no rule. Per arm: reviewed
returns kept and lost by stage (L3 background, the input cap, DBSCAN noise, the height band), the
share of fragmented instants' missing returns at each stage, pedestrians and trucks apart, and
the 20 to 35 m gap returns by stage. An arm that moves a quarter or more of the gap returns from
background into a cluster is a lead for the W3 fix; one that moves none says the fix is a rule
of its own, not a Stage B arm. Nothing here changes an arm of l3bg0009.

**Fixed before the recordings (2026-10-20).** Each arm is recorded with `velocity lidar
pcap-replay --observations` at `main` (`8c94e23df`), which since #812 takes the replay
experiments: `cmr-dwell` adds `--experiment dwell_policy`, `cmr-cell` adds `--experiment
region_overrides_cell_tercile`. The replay settings are the earlier fate report's (geom0004):
kirk0 whole, `--start-seconds 6 --warmup-seconds 6 --require-settled`, UDP port 2369, case id
kirk0, each container verified foreground-complete; fate is read on the reviewed pack's
`kirk0-tuning` split with the default range bands (20, 35, 50 m). `a0` is today's defaults, which
since #787 carry the once-substituted L3 (closeness 2, margin 0.3, neighbour 5), not the L3 the
earlier report called "shipped", so its row is reported for reference and not compared with that
report's. A Stage B arm "moves" gap returns relative to `cmr`, the set both Stage B arms add to:
the share of `cmr`'s 20 to 35 m gap returns lost to L3 background that the arm puts into a cluster.

**What it does not establish.** A fragmentation rate (that is W3's measure, geom0003's); anything
on the corpus, which has no reviewed returns.
