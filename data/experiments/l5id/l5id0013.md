# Reacquisition acceptance on current defaults

The owner requested cloud development and one reviewable PR for this backlog
item. The November 2 report found fewer duplicates but more brief/clutter tracks.
This run refreshes the tuning evidence after the foreground/mean-centre changes;
it does not replace label0001's independent identity gate.

## Rule, before this run's replays

Keep l5id0004's labelled limits: candidate matches at least 0.98 of baseline;
HOTA and IDF1 no lower than baseline minus 0.005; no more ID switches; and
fragmentations at most baseline times 1.1 plus 1. Report every number against a0
and the tentative option against body-older. Also report brief tracks, clutter,
duplicate pairs and observed vehicle frames using the existing noise screen.
No quality gate is tuned on these windows.

Numeric tuning passes are insufficient evidence for acceptance. A pass requires
a frozen, reviewed held-out per-frame score; the corpus and W5 geometry gates
remain additional requirements. No default changes in this cloud PR. If labels,
frozen splits or downloads are missing, record that as insufficient evidence,
retain exact provenance and leave the labelled acceptance step open.
