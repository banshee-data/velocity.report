# l6cls0001: what the class gate holds back

**Question.** Under the published box the provisional following field run finds 212 s of valid
following time on the first segment of 23 sites, and the class gate suppresses 767 s of the
1,593 s it accounts (l8fol0003). On kirk0 most reviewed vehicles end classed `dynamic` because the
car rule asks a large track to be fast (mean speed over 5 m/s or peak over 7.5 m/s) or tall (mean
height over 1.2 m), and slow traffic seen from 2.3 m without its lower body is neither (l8fol0002).
Before anyone changes the classifier: how much valid following time is the class gate holding
back on the corpus, and how much of it would a rule that keeps the size test but replaces the
speed-or-height test with motion release?

**Method.** A counterfactual on the field run's own reading, no replay. The box reader takes a
track's class from `lidar_tracks.object_class` for the whole passage, so rewriting that column on
a copy of each case's l8fol0003 box-arm evidence database and running the field run again gives
exactly what the field run would report had the classifier ended those tracks so. Three arms, all
on the defaults' replays:

- `as-run`: the labels as the tracker wrote them (l8fol0003's box arm, read again for the
  comparison).
- `size-moving`: a track the classifier ended `dynamic` becomes `car` when it passes the car
  rule's own size test (mean box length over 3.0 m or mean width over 1.5 m, the track's
  `bounding_box_length_avg` and `bounding_box_width_avg`) and its peak speed is at least 3 m/s,
  the following selector's speed floor. No other label changes.
- `all-dynamic`: every `dynamic` track becomes `car`: an upper bound on what any class change can
  release, which admits non-vehicles by construction.

**Reading, written before the reruns (2026-10-20).** A measurement; no default and no classifier
changes. Per arm, pooled and per site: valid following seconds, accounted seconds, seconds
suppressed for class, and encounters. For `size-moving`: the tracks relabelled, and how many of
them are not vehicle-sized (lasting 2 s or more with a p90 cluster longer side of 3.0 m or more,
l8fol0001's definition), a label-free proxy for false applicability.

What it decides: if `size-moving` releases at least half of the class-suppressed seconds that
`all-dynamic` releases, with no more than one in ten of its relabelled tracks short of
vehicle-sized, a classifier experiment on that rule is worth specifying (scored by the class
measure on kirk0 with false applicability held at zero, and held out once label0001 exists). If
it releases less, the rule's features (the measured height and speed) are the problem, not its
thresholds, and the ground line (the box's base on the surface, ground0004) comes first.

**What it does not establish.** That any relabelled track is a vehicle: the corpus has no class
labels. That the classifier would reach the same label online, where it decides on running
features rather than the track's final means. Anything held out.
