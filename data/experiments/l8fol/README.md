# l8fol: L8 following

Experiments on the following-distance metric: how often both parties of a pair are observed,
which physical endpoint source feeds the gap, what class evidence the gate needs, what the limits
are and what a held-out window scores. Specs are named `l8fol0001` onwards; see the
[README](../README.md). The metric's design is the
[behaviour analytics plan](../../../docs/plans/lidar-behaviour-analytics-plan.md); its field
run is the [provisional headway report](../../../docs/lidar/operations/headway-report-oracle.md).

Answered: [l8fol0002](l8fol0002.md), the class the gate reads on kirk0's reviewed vehicles
([report](../../../docs/lidar/operations/following-class-evidence-kirk-2026-10.md)).
