# pose: sensor pose

Experiments on where a static sensor stood and which way it faced: the settled background
registered against USGS 3DEP and DataSF through Gerardus (`gerardus register`), the gates that
decide `registered`, and what velocity.report's background has to be for that to work. The
Gerardus side is [MVP 0](../../../docs/plans/lidar-visualiser-gerardus-alignment-plan.md) and
Gerardus's `docs/plans/MVP-REGISTER-808581.md`; the registration status per site is Gerardus's
`docs/REGISTRATION-STATUS.md`. Specs are named `pose0001` onwards; see the [README](../README.md).
