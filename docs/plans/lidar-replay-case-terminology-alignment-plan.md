# LiDAR clip terminology alignment

- **Status:** Superseded by [Phase 1 under D-31](platform-vocabulary-and-data-model-plan.md#phase-1-under-d-31-three-renames)
- **Canonical:** [Platform vocabulary](../platform/PLATFORM.md#platform-vocabulary)

The old scene-to-replay-case proposal is superseded. The accepted noun is **clip**.
The programme owns the schema, Go, API, web and macOS cutover and the
[compatibility register](../platform/operations/compatibility-register.md) owns surviving names.
No replay-case route or type alias is introduced.
